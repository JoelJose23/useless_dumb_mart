### Project Description

UselessMart™ is an intentionally terrible e-commerce platform designed to provide the worst possible online shopping experience while maintaining surprisingly clean and functional software architecture.

It sells completely useless products, introduces unnecessary obstacles at every stage of the purchasing process, and somehow still manages to complete the order.

### The Problem (that doesn't exist)

After the rise of AI, all the websites are like robots, perfect, same and boring.

Every button works.  
Every checkout process makes sense.  
Every interface tries to help the user.

**We decided this was a problem.**

Modern websites have become too predictable, too convenient and far too concerned about user satisfaction.

Where is the confusion?  
Where is the suffering?  
Where is the button that runs away when you try to click it?

The internet needed something worse.

### The Solution (that nobody asked for)

Introducing **UselessMart™** — an e-commerce platform that actively works against its users.

Our platform features:

- Completely useless products
- An unnecessarily difficult academic CAPTCHA
- A secret phrase that bypasses the CAPTCHA
- Buttons that literally run away from your cursor
- Reversed scrolling
- Ridiculous checkout fees
- Suspicious payment verification
- Randomly encrypted OTPs
- Fake loading screens
- Completely unnecessary popups
- Toxic motivational messages
- A shopping cart that questions your life choices
- An order that may or may not become a rock
- A refund system designed to make you regret buying anything
- A uselessness score to measure how badly things are going

All of this is wrapped in a clean, functional React application.

Because if we're going to build something useless, **we might as well engineer the uselessness properly.**
